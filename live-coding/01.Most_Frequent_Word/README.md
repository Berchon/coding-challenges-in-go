# Palavra mais frequente

### Descricao

Implementar uma funcao que recebe uma lista de palavras e identifica qual palavra aparece com maior frequencia. A solucao percorre a lista, contabiliza as ocorrencias em um mapa e retorna a palavra que alcancou a maior contagem durante o processamento.

### Requisitos

- Receber uma lista de strings como entrada.
- Retornar a palavra mais frequente da lista.
- Retornar erro quando a lista estiver vazia.
- Contabilizar a frequencia de cada palavra usando uma estrutura de mapa.
- Em caso de empate, manter a primeira palavra que atingiu a maior frequencia durante a iteracao.
- Exibir no console a frequencia calculada para cada palavra.
