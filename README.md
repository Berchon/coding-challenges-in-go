## 🏃 Como Executar e Debugar

### 1. Pelo VS Code
Abra qualquer arquivo `.go` e pressione:
- **`F5`**: Inicia o Debug no arquivo aberto em foco.
- **`Ctrl + F5`**: Roda o arquivo aberto sem depuração.

### 2. Pelo Terminal
Você pode rodar diretamente da raiz indicando o caminho:

```bash
# Exemplo HackerRank
go run "hackerrank/Algorithms/01.Warmup/Easy/01.Solve Me First/main.go"

# Exemplo LeetCode
go run "leetcode/1.array_string/medium/151. Reverse Words in a String/main.go"

# Exemplo Live Coding
go run "live-coding/01.Most_Frequent_Word/main.go"

# Rodar todos os testes de Live Coding
go test -v ./live-coding/...
```
